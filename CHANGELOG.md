# Changelog

## v0.1.0

The first release of `cad-reverse-engineer`: a skill and its CLI, `cadrev`, for rebuilding a published object, from a single part up to a mechanism, as a parametric build123d model that anyone can audit, number by number, against its sources. It is built for Fable 5.2 and [benchmarked](docs/benchmark.md) across Anthropic's and OpenAI's frontier models.

The [README](README.md) says how it works, how to install it and what it needs. [`examples/`](examples) holds five worked reconstructions, four of them built by a fresh agent from the skill and the sources alone.
