# Unconfirmed readings downgrade the status

A project whose only shortfall is figure readings that no human has yet confirmed reports VERIFIED PENDING REVIEW, not VERIFIED and not NOT VERIFIED. Treating them as warnings let an agent's own transcription earn VERIFIED unseen, which is the false claim this project exists to prevent; treating them as errors would make every agent-driven run end in failure at the one step a human must take. The third status keeps the headline honest without breaking the agent-driven flow.
