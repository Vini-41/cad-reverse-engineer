# A reconstruction is one device, modifiable and kinematic

A reconstruction rebuilds one published device, from a single part up to a whole mechanism (a gripper with its mount, not the vehicle it is shown on), as CAD that can be modified, simulated kinematically and, with its plan, made (ADR-0021). Motion is optional per project: a static project stays valid and its report says so. `tolerance` is the model's, how closely it realises a value, and not what a shop works to. Inputs are the published sources plus any geometry the authors released; the reconstructor's own measurements of a physical object are out. The model is for collaborators, so the evidence discipline holds in full for motion too: a stated range or angle is ledgered, and a check confirms it on the posed model.

We chose this over two wider scopes. Whole robots need several devices and nested subassemblies, a separate effort (format 2), and come back when a real project needs a second device. Behavioural simulation (reproducing a paper's grasp or perching results) would mix the reconstruction's correctness with the simulator's contact and friction accuracy, so a failed check could not say which was wrong; it comes back if a kinematic model is not enough to answer a question asked of the device. This ADR first kept fabrication out as well, ranked last behind modifying and simulating; ADR-0018 and ADR-0021 brought it in.
