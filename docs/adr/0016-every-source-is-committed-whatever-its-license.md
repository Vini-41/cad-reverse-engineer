# Every source is committed, whatever its license

Every registered source is committed with its project, and a source entry has no `license` field: the template's `.gitignore` leaves `sources/` alone, and a leftover `license` key is a `[schema]` error like any other unknown key. This supersedes ADR-0003. A project must rerun from a clone for its VERIFIED claim to be checked, and ADR-0003 kept every source outside CC0, CC-BY and CC-BY-SA out of the clone, which also kept those objects out of the runs CI can make. Whether a file may be published is the user's call, made when they push, not a rule the verifier can settle from an SPDX id: they can ignore a source by hand, and `cadrev check` then names it `[source-missing]` in a clone, with its `url` to download it from. We rejected quietly ignoring a leftover `license` key, which would keep a rule alive only for old projects when one deleted line fixes each.
