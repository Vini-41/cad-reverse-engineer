# Each part has a drawing dimensioned by its checks

A verification run writes `build/isometric.png`, the assembly as built, and `build/drawings/<part>.png` for each part: front, top and right views in third-angle projection beside an isometric one, hidden edges dashed. The dimensions on a drawing are its part's checks: each unposed `bbox`, `distance`, `angle` and `diameter` check that reads the part in its own frame is drawn where it reads, at the value as built, blue where it passes and red where it fails; an envelope no check compares is a reference dimension in parentheses; a declared thread (ADR-0018) is drawn and called out. report.md opens on the isometric view, and lists the checks part by part, each part's under its drawing, with the checks that read the assembly after them. `up: y` in project.yaml names the views for an object standing on Y, as released geometry from a Y-up CAD program does.

This came from a mechanical engineer's review of v0.1.0: one table of every check is not how a part is verified, and the first things to see are an isometric view and a drawing of each part. A reviewer now verifies a part on one sheet, and a datum on the wrong feature shows as a dimension in the wrong place.

We rejected dimensioning from the params, which have no place on the geometry and would draw what the model was told rather than what a check evaluated; and a drawing as a pass or fail of its own, since it only shows the checks' results. We rejected a shaded render for the isometric view: hidden-line projection needs no GPU, runs the same in CI, and is what a drawing shows. A drawing is not a fabrication drawing: it carries no tolerances, which are the plan's to state (ADR-0021).

The drawings replace figure overlays, the model's edges drawn over a figure at a scale calibrated from one stated length, which `overlays.yaml` listed until v0.2.0. An overlay added no pass or fail, a figure that prints no length (every patent drawing) could not be calibrated, and no project has written one since the drawings: a part's outline is compared with its figure on its sheet.
